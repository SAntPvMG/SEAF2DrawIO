# Переписка: ярлык локации (dc_label / office_label) и рамка mxCell в Draw.IO

Дата фиксации: 2026-05-06.

## Проблема

На страницах детализации ЦОД (`dc`) и офиса (`office`):

- Подпись объекта (**object label**, HTML в атрибуте `label`) отображалась **в правильном месте**.
- Геометрия и выделение (**mxCell** со стикером ярлыка, `vsdxID=13090`) **не совпадали** с подписью — «уезжала» рамка выделения (ghost box).

## Причина

В diagrams.net подпись `<object … label="…">` привязана к **основной вершине**, у которой **`id` совпадает с `id` объекта**.

Было сделано разведение идентификаторов: `mxCell id="{{id}}__loc_mx"` при `object id="{{id}}"`. Из‑за несовпадения id редактор вёл себя неконсистентно: HTML-подпись и рамка вершины расходились.

## Решение

В паттернах снова задано **`mxCell id="{{id}}"`** — тот же id, что у обёртки `<object id="{{id}}">`:

- `data/patterns/dc.yaml` — блок `dc_label`
- `data/patterns/office.yaml` — блок `office_label`

Логика **`resize_location_label_to_cover_segments`** в `seaf2drawio.py` по-прежнему находит ячейку ярлыка по маркеру стиля `_LABEL_STENCIL_MARK` (`vsdxID=13090`); менять код для этой правки не требовалось.

### Замечание про дубликаты OID на разных страницах

На главной схеме компактные иконки ЦОД/офиса используют **`mxCell` без явного `id`**, поэтому конфликта с вершиной `id="{{id}}"` только на странице детализации в одном `.drawio` нет.

Если в будущем проявятся артефакты из‑за **двух `<object id="…">` с одним семантическим OID на разных диаграммах** в одном файле, возможным следующим шагом будет уникализация id объектов на детальных страницах при сохранении семантического OID в данных.

## Проверка

После генерации:

```bash
python3 -X utf8 seaf2drawio.py
```

В выходном `.drawio` у ярлыка локации на странице ЦОД/офиса должна быть строка вида:

```xml
<mxCell id="jupiter.dc.moscow_dc01" … vsdxID=13090 … parent="001">
```

(идентификатор совпадает с `object id` того же объекта.)

В Draw.IO рамка выделения должна совпадать с белой подложкой и текстом подписи.

## Связанный код и константы

| Что | Где |
|-----|-----|
| Пересчёт геометрии ярлыка | `seaf2drawio.py` → `resize_location_label_to_cover_segments`, `refresh_location_label_mxcells_after_swimlane_geometry` |
| Маркер стикера ярлыка | `_LABEL_STENCIL_MARK = 'vsdxID=13090'` |
| Паттерны XML | `data/patterns/dc.yaml` (`dc_label`), `data/patterns/office.yaml` (`office_label`) |
