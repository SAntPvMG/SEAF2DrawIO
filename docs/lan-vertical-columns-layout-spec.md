# Спецификация: много LAN в сегменте — вертикальные колонки (`deep`, `offset`)

## Требование (продукт)

Параметры паттерна **`lan:`** в [`data/patterns/dc.yaml`](data/patterns/dc.yaml) и [`data/patterns/office.yaml`](data/patterns/office.yaml):

- **`deep`** — порог числа объектов LAN по вертикали (в смысле «сколько полосок LAN в сегменте»; см. ниже триггер).
- **`offset`** — базовый шаг паттерна; расстояние между **колонками** LAN задаётся как **`offset * 2`** (px).

### Условие переключения раскладки

Если в сегменте число LAN **больше**, чем **`lan.deep`**, то не использовать прежнюю схему «каждая LAN — отдельная строка по вертикали с равномерными зазорами», а применить колоночную схему:

1. **Вместимость одной колонки по вертикали:** не более **`deep + 3`** полосок LAN, расположенных **друг под другом** (вертикальный стек внутри колонки).
2. Если LAN больше **`deep + 3`**: начать **новую колонку**:
   - вертикальное начало — **с того же верхнего уровня**, что и первая колонка (верх стека совпадает с верхом первой колонки);
   - горизонтальный сдвиг новой колонки относительно предыдущей — **`lan.offset * 2`** (в дополнение к ширине уже размещённого содержимого колонки — это нужно явно зафиксировать при реализации, см. раздел «Реализация»).
3. Пока LAN не кончатся: повторять колонки из **`deep + 3`** полосок с теми же правилами.

### Пример чисел из `dc.yaml`

При **`deep: 4`**, **`offset: 100`**:

- порог «много LAN»: больше **4** LAN в сегменте;
- в колонке до **`4 + 3 = 7`** LAN по вертикали;
- между колонками дополнительный горизонтальный зазор по спецификации: **`100 * 2 = 200`** px (точная привязка — к левому краю следующей колонки или между правым краем предыдущей колонки и левым следующей — задаётся в коде однозначно).

## Текущее состояние кода

Реализовано в [`auto_layout/segment_intrinsic_layout.py`](auto_layout/segment_intrinsic_layout.py), **`compute_intrinsic_band_layout`**: при **`len(row_specs) > lan_pat['deep']`** список режется на чанки по **`deep + 3`**; внутри чанка строки идут **вниз** с шагом **`row_h + LAN_COLUMN_VERTICAL_GAP_PX`** (константа **30 px**); верх всех колонок **`cur_y_top`** (вертикальное центрирование блока по высоте сегмента через **`gap_top`**); следующая колонка начинается с **`col_right_max + lan.offset * 2`**. Учитывается **`fw_strip_anchor_lan`** через **`temp_lan_right_edge`** как раньше. Ключ кэша intrinsic включает суффикс версии (например **`v25-lan-vertical-columns-vgap`**).
